Map-based localisation LiDAR + IMU against a prior map from a separate survey flight

The map is built from an earlier survey flight using its estimated VIO+LIO poses (so it carries drift), on an independent sample of the terrain. The live flight is a different trajectory over a scene with changes (trees removed, boxes added). It starts from a kidnapped guess (6 m, 35° off), recovered by a coarse (x, y, yaw) search plus ICP. Errors are absolute, with no trajectory alignment.

Honest scope

  • All sensors are simulated. No vehicle, sensor rig or real dataset was used: dataset hosts were not reachable from the build environment.
  • Camera feature tracking is idealised (perfect IDs, plus pixel noise, dropouts and 2% outliers). There is no image-level detector or KLT here. Camera features ignore occlusion.
  • LiDAR motion compensation uses a constant-twist model inside each sweep; the simulator moves the sensor along the true trajectory, so the model error is realistic but not zero.
  • The LiDAR lever arm is not adopted: an online extrinsic state in the filter did not beat the CAD value in this simulation (see the calibration table). The camera lever arm uses a bench target at 1.2 m.
  • Filter initial pose and velocity come from ground truth, as is usual for simulated odometry benchmarks. Map-based localisation, in contrast, starts from a deliberately wrong guess.
  • The next step is running the same code on EuRoC / Newer College bags, then on a real rig.
